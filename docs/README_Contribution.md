# GymManager – Contribution UML et Base de données

## 1. Présentation

Cette contribution concerne la conception UML, la modélisation Merise et la création de la base de données du projet GymManager, une application de gestion d'une salle de sport.

## 2. Conception UML

Les travaux réalisés comprennent :
- Diagramme de cas d'utilisation.
- Diagramme de classes.
- Diagrammes de séquence.

## 3. Modélisation Merise

- Modèle conceptuel de données (MCD).
- Modèle logique de données (MLD).

## 4. Base de données

- SGBD : PostgreSQL 17.6.
- Nom de la base : gymmanager_db.
- Schéma : public.
- Scripts SQL de création et de vérification.
- Jeu de données fictives pour les tests.

## 5. Documentation

- Dictionnaire des données.
- README de la base de données.
- Diagrammes MCD et MLD.

## 6. Objectif

Fournir aux développeurs une conception structurée et une base de données documentée pour faciliter le développement du backend et du frontend de GymManager.
